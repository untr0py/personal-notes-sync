Personal Notes Sync

A personal utility operated by Dean Reading to synchronize an Obsidian notes folder between Google Drive and a local computer using the open-source rclone application.

This is for the owner's personal use. It is not a public sign-up service or an application operated by Google or Obsidian.

Privacy policy · Terms of use · Contact

Privacy policy

Effective October 25, 2026.

The utility requests Google Drive read/write permission to list, download, upload, update, and delete files as needed for two-way synchronization. Google authorization may cover the account's Drive, but the local configuration targets the selected notes folder and its backup location.

File contents and metadata are processed on the owner's computer and exchanged with Google Drive. OAuth credentials are stored locally to permit unattended synchronization. Notes and credentials are not published on this website or stored in this website's GitHub repository.

The operator does not sell Google user data, use it for advertising, or use it to train AI models. The utility does not send notes to a separate application server. Google Drive and GitHub process information under their own privacy policies. GitHub hosts this static information page and may collect standard web request information; this page adds no analytics or tracking scripts.

Synced files remain on the computer and Google Drive until removed by the owner. Backup copies and Drive trash may remain until separately removed. The owner can stop the sync job and revoke access in Google Account settings at any time. Revoking access does not delete existing file copies.

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

For questions, contact the operator through the GitHub profile or the repository's issue tracker. Do not post private notes or credentials in public issues.

Terms of use

This utility is configured for the owner's personal use and is provided as is, without warranties. Synchronization can propagate edits and deletions. The owner is responsible for maintaining backups and reviewing conflicts. No paid service or availability guarantee is offered.
